Key fact about the whole codebase: the Platform shell (login, browsing, downloads, home screen) and the Core Simulation Runtime (the actual VR training experience) are two almost entirely separate programs sharing one Unity project. The only bridge is SessionManager ↔ SimulationManager — see Fig. 07. The Location system is completely disconnected (Fig. 08).

FIG. 02

Core runtime — simulation flow

SimulationManager → SimulationState → Interactions.

Click a box or connection for details.

Step save-state (new): restart previously only reset each Interaction's internal flags — moved objects stayed moved. StepStateComponent (abstract CaptureStepState()/RestoreStepState()) is now implemented by GrabInteraction/DetectInteraction automatically, plus SceneObjectSnapshot (generic transform/enable/Animator undo for any prop) and StepStateHook (UnityEvent passthrough for any other script) via SimulationState.extraStepStateHooks. Two granularities reuse the same contract: RestartCurrentState restores the whole step's true top-of-step baseline; RestartCurrentInteraction restores only the currently-running interaction's own baseline (re-captured right before its turn), so it never undoes an earlier interaction's legitimate progress. Pause/Resume needed no changes — all grabbable objects use kinematic, no-gravity Rigidbodies with purely transform-driven movement, so canInteract=false already fully freezes the scene.

v2.0/Simulation — orchestration core 6 files

SimulationManager
Top-level state machine driving the list of SimulationStates, pause/resume, restart (step + interaction), mode selection (Guided/Assessment/FreeRoam). Talks to: SimulationState, SessionManager, AssessmentManager, PartsIdentificationManager, SoundManager, Interactions.
SimulationState
One per training step; owns listOfInteractions + extraStepStateHooks, runs the sequence coroutine, drives prompts/teleport/assessment hooks, captures/restores step save-state. Talks to: AssistantManager, AssessmentManager, TeleportManager, Interactions, StepStateComponent, DelayedEvent, SimulationManager.
GrabManager
Thin DontDestroyOnLoad singleton holding left/right GrabPinchDetector refs.
PreviewManager
Singleton; pauses sim and plays a context video based on current interaction type. Talks to: SimulationManager, DetectInteraction, GrabInteraction, UIInteraction/IdleInteraction/GazeInteraction.
ContaminationManager
Per-zone contamination + hand-speed detection, simultaneous zones. See Fig. 03.
FirstAirManager
Per-zone first-air-break detection — architectural mirror of ContaminationManager, minus hand-speed. See Fig. 03.

v2.0/Simulation/StepState — step save-state 3 files

StepStateComponentabstract
CaptureStepState()/RestoreStepState() contract shared by every step save-state hook.
SceneObjectSnapshot
Generic "put this scene object back" component — undoes enable/disable, transform/parent, and any Animator's parameters + exact per-layer state/time, in one component.
StepStateHook
UnityEvent passthrough (onCaptureStepState/onRestoreStepState) so any existing script can be made restart-safe from the Inspector with zero code changes.

v2.0/Interactions(Previously State) — interaction types 6 files

Interactionsabstract base
canInteract property + OnCanInteractChanged hook, InteractionTimer, highlight/radial-UI plumbing, lifecycle (Start/Suspend/Complete/Reset), no-op CaptureStepState/RestoreStepState.
GrabInteraction
Offset-based grab (pinch or proximity), pose locking, reset-on-release, grab-collider mirrors canInteract; overrides CaptureStepState/RestoreStepState to snapshot/restore its own transform+parent. Talks to: GrabPinchDetector, HandPoseLock/ControllerPoseLock, RecordedPose/BakedPose, ProximityGrabUI, GrabHighlightController, MoveToHelper, SoundManager.
DetectInteraction
Trigger-zone detection of one or more GrabInteraction objects, discard/dissolve on completion; overrides CaptureStepState/RestoreStepState to fan out to each detected object's own GrabInteraction. Talks to: GrabInteraction, AssistantManager (BotDiscard), SoundManager, HapticManager.
GazeInteraction
SphereCast + proximity gated "look at object" interaction. Talks to: SoundManager, HapticManager, RadialInteractionUI.
IdleInteraction
Timer-only or manual-advance interaction; no physical detection.
UIInteraction
Either a scene-authored panel/button or fully bot-handled via AssistantManager.TriggerBotUI. Talks to: CustomButton, AssistantManager, PanelButtonController.
